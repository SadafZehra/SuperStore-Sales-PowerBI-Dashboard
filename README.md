# SuperStore Sales Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **SuperStore Sales Dashboard** developed using **Microsoft Power BI** as part of a **Data Visualization** course.

The dashboard transforms raw SuperStore business data into meaningful and interactive visual insights, helping users understand sales performance, profitability, customer behavior, regional trends, and shipping performance.

## 🎯 Objectives

The main objective of this project is to analyze business performance through interactive data visualization and provide actionable insights for better decision-making.

## 📌 Dashboard Features

The dashboard provides a visual overview of:

* **Sales Performance** – Analysis of overall sales and sales trends.
* **Profit Analysis** – Evaluation of profitability and profit distribution.
* **Order Tracking** – Overview of order volume and order-related trends.
* **Regional Sales Distribution** – Comparison of sales performance across different regions.
* **Customer Segment Analysis** – Analysis of sales across different customer segments.
* **Shipping Performance** – Evaluation of shipping modes and delivery-related performance.
* **Sales Forecasting** – Short-term sales forecasting to identify potential future trends.

## 📈 Key Insights

The dashboard enables users to:

* Monitor overall business and sales performance.
* Identify profitable and underperforming areas.

## 🚀 How to Use

1. Download the `.pbix` Power BI file from this repository.
2. Open the file using **Microsoft Power BI Desktop**.
3. Interact with the dashboard using filters, slicers, and visualizations.
4. Explore sales, profit, regional, customer, shipping, and forecasting insights.
